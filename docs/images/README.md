Screenshots and diagrams for the notes.

Drop image files here and reference them from a note as:

    ![what it shows](images/av-01-choice-diagram.png)

They are copied verbatim to docs/images/ at build time, so the same path
works in local preview and on the published site.

Naming: <page-slug>-<what-it-is>.png  — e.g. av-01-choice-diagram.png
Keep them under ~300 KB; crop rather than shrink, so text stays readable.
